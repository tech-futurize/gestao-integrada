## Visão Geral

Look-Ahead de 6 semanas — exibe as atividades do cronograma que têm sobreposição com a janela das próximas 6 semanas (calculada no front a partir de hoje). Controle de restrições por 6 categorias via checkboxes inline. Vínculo bidirecional com o módulo de Cronograma via FK `tarefa_cronograma_id`.

## Schema — `itens_6wla`

| Coluna | Tipo | Notas |

## Dados do Cronograma (read-only via JOIN)

Consumidos via segundo `useQuery` para `TarefaCronograma` (filtro `tipo: "Atividade"`) e merged no front:

| Campo exibido | Coluna em `tarefas_cronograma` |
|---------------|-------------------------------|
| Nome da atividade | `nome` |
| Área / Disciplina | `area`, `disciplina` |
| Status | `status` |
| %Prev / %Real | `avanco_previsto`, `avanco_realizado` |
| Semanas ativas | calculado via `getSemanasBadge()` |

## KPIs — 7 Cards Superiores

```
[ Total Atividades ] [ Proj/Eng ] [ Mat ] [ MO ] [ Eq ] [ Ext ] [ Info ]
    Cobalt/Ciano         amber     amber  amber  amber  amber  amber
```

- **Total**: número de itens no 6WLA do projeto
- **6 categorias**: contagem de atividades com aquela restrição marcada (checkbox = true)

## Pills S1–S6 — Filtro por Semana

Calculadas via `getSemanas(hoje)` em `sixWLAUtils.js`:
- S1 = semana atual (começa na segunda-feira)
- S2–S6 = semanas seguintes
- Multi-select: clicar numa pill alterna inclusão/exclusão do filtro
- Tooltip mostra intervalo `DD mmm – DD mmm`
- Tabela filtra linhas que têm sobreposição com pelo menos uma semana ativa

## Banner de Auto-Sync

Aparece automaticamente quando há atividades do cronograma (dentro da janela de 6 semanas) que ainda **não** têm registro em `itens_6wla`. O usuário pode importar em massa clicando "Importar automaticamente" ou fechar o banner.

Lógica: `tarefasNaJanela.filter(t => !existingTarefaIds.has(t.id))` → se `> 0`, exibe banner.

## Modal — Adicionar do Cronograma

`AdicionarCronogramaModal.jsx` — Dialog com:
- Campo de busca (nome, área, disciplina)
- Lista com checkbox multi-select
- Botão "Adicionar N atividade(s)" habilitado somente com seleção

Ao confirmar: `bulkCreateMut` cria registros em `itens_6wla` com todos os booleanos de restrição = `false`.

## Tabela — `SixWLATable.jsx`

Colunas: Atividade · Área/Disc. · Sem. (badges S1–S6) · %Prev · %Real · Proj/Eng · Mat · MO · Eq · Ext · Info · Obs. · [Remover]

- Checkboxes de restrição: `onCheckedChange` → `updateMut` imediato
- Observação: Popover com `<Textarea>` — salva ao fechar o popover
- Remover: botão Trash2 — remove o item do 6WLA (não afeta o cronograma)
- %Real colorido: verde ≥100%, âmbar ≥50%, vermelho >0%, cinza = sem dado

## System States

| Estado | Implementação |
|--------|---------------|
| Loading | Linha "Carregando..." centralizada na tabela |
| Empty (sem projeto) | `<PageEmptyState>` com descrição |
| Empty (tabela) | Linha "Nenhuma atividade no período selecionado" |
| Error | `<AlertCircle>` com mensagem e instrução de recarregar |
| Success | Toast `variant="success"` ao importar atividades |
| Error mutation | Toast `variant="destructive"` com `e.message` |

## Utilitários — `sixWLAUtils.js`

| Função | Descrição |
|--------|-----------|
| `getSemanas(hoje)` | Retorna array de 6 semanas `{label, weekNumber, start, end}` |
| `getSemanasBadge(tarefa, semanas)` | Retorna labels das semanas que sobrepõem as datas previstas da tarefa |
| `formatData(date)` | Formata Date como `"23 jun"` em pt-BR |

Semanas começam na **segunda-feira** (ISO week convention).

## Dashboard Integration

`src/components/dashboard/ModulosResumo.jsx` exibe no card "Planejamento":
- **Itens 6WLA**: `itens6wla.length`
- **Sem Restrição**: `%` de itens sem nenhuma restrição ativa (equivalente ao PPC na lógica de pronto-para-executar)

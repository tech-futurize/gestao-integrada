Como mostrar que um filtro está ativo?

Quando o usuário seleciona opções num filtro, como o botão deve indicar isso?

▼Disciplina
▼ Status 2
▼ Etapa 4
✕ Limpar

A — Badge numérico

Botão fica azul com um badge mostrando a quantidade de opções selecionadas. Botão "Limpar" aparece quando há filtros ativos. Compacto — ideal para muitos filtros na mesma toolbar.

▼Disciplina
▼ Status: Ativo, Mitigado ✕
▼ Etapa: 4 selecionadas ✕

B — Rótulo com valores (até 2) ou contagem

Botão exibe os valores selecionados no label ("Status: Ativo, Mitigado"). Quando há 3 ou mais, mostra contagem ("Etapa: 4 selecionadas"). Ícone ✕ limpa aquele filtro individualmente.

▼Status 2
▼Etapa
Filtros: Status: Ativo ✕ Status: Mitigado ✕ Limpar tudo

C — Badge no botão + chips abaixo

Botão usa badge numérico. Uma linha de chips aparece abaixo da toolbar mostrando cada valor selecionado individualmente, com ✕ para remover um a um. "Limpar tudo" remove todos. Máxima visibilidade dos filtros ativos.

Clique para selecionar sua preferência.

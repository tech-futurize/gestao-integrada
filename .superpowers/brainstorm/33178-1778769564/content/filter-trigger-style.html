A — Botões inline na toolbar

Cada filtro é um botão separado que abre um dropdown com busca + checkboxes. Badge numérico mostra quantas opções estão ativas. Padrão usado em Notion, Linear, Jira.

B — Painel unificado de filtros

Um único botão "Filtros" abre um painel/drawer lateral com todos os campos disponíveis agrupados por seção. Cada seção tem busca + checkboxes. Padrão usado em e-commerces e ferramentas de BI.

C — Barra colapsável acima da tabela

Uma barra fixa abaixo da toolbar principal que expande/colapsa e mostra todos os filtros lado a lado com busca + checkboxes. Fica sempre visível quando há filtros ativos.

Clique para selecionar. Pode escolher mais de um para combinar ideias.
